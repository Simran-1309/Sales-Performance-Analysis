Sales Performance Analysis Dashboard

Project Overview
An end-to-end Sales Performance Analysis project using Excel, MySQL and Power BI. This project analyses sales transactions to identify revenue trends, profitability, customer behaviour, product performance and regional sales patterns.

Tools & Technologies
- Microsoft Excel – Data cleaning and preprocessing
- MySQL 8.0 – Data storage, SQL queries and analysis
- Power BI Desktop – Interactive dashboard development
- DAX – KPI calculations and business metrics

Dataset
Sample Superstore dataset containing 9,994 sales records and 21 columns, including order dates, customer details, product categories, sales, quantity, discounts and profit.

Project Workflow
1. Cleaned and validated the dataset using Excel Power Query.
2. Imported the cleaned CSV into MySQL.
3. Created SQL queries for data validation and business analysis.
4. Developed six DAX measures in Power BI.
5. Created an interactive dashboard with KPI cards, charts and slicers.
6. Validated Power BI sales calculations against MySQL results.

Key Business Findings
- Technology generated the highest category profit.
- West was the leading region by sales.
- Furniture had substantially lower profit than the other two product categories.
- Some product sub-categories generated negative profit.
- Sales increased considerably from 2015 through 2017.

Project Outcome
Developed an interactive sales analytics dashboard and performed end-to-end data analysis using Excel, SQL and Power BI.
